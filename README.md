# Kite Writer

한글(HWP/HWPX) 문서를 중심으로 Word·PDF·Markdown 문서까지 열어 편집하는 데스크톱 워드프로세서입니다.
Electron + React + TypeScript + TipTap(ProseMirror) 기반이며, HWP/HWPX/DOCX 변환기는 외부 라이브러리 없이 직접 구현했습니다.

## 실행

```bash
npm install
npm run dev        # 개발 모드 (Vite + Electron)
npm run build      # 타입 검사 + 화면/메인 프로세스 빌드
npm start          # 빌드 결과 실행
npm run dist       # 버전 +1 후 Windows 설치 파일(release/) 만들기 (dist:same 은 버전 그대로)
npm run dev:web    # 브라우저에서만 실행 (파일은 내려받기로 저장)
```

## GitHub 릴리스

```bash
npm run release          # 패치 +1 → 커밋 → v<버전> 태그 → push
npm run release:minor    # 1.0.3 → 1.1.0
npm run release:major    # 1.1.0 → 2.0.0
```

태그가 올라가면 `.github/workflows/release.yml` 이 윈도우 실행기에서 설치 파일(`Kite Setup <버전>.exe`)과 스토어용 appx 를 만들어 GitHub 릴리스에 붙인다. 커밋하지 않은 변경이 있으면 멈춘다.

## 지원 형식

| 형식 | 열기 | 저장 | 비고 |
|---|---|---|---|
| HWPX | ✔ | ✔ | 글자/문단 모양, 표(셀 병합·배경·선 없음), 그림, 각주, 머리말/꼬리말, 쪽 번호, 하이퍼링크, 개요·문단 번호, 글상자 |
| HWP 5.0 | ✔ | ✔ | 위와 같음. 암호/배포용 문서는 열 수 없음 |
| DOCX | ✔ | ✔ | 스타일 상속, 번호 목록, 병합 셀, 필드, 각주, 머리말/꼬리말 |
| DOC | ✔ | – | Word 설치 시 서식 포함 변환, 없으면 LibreOffice → 텍스트 순으로 대체 |
| PDF | ✔ | ✔ | PDF에 든 글꼴로 그리고 줄바꿈·글자 위치를 원본과 같게 맞춤, 표·배경 상자·구분선·직인 재구성 / PDF로 저장(인쇄 품질) |
| Markdown | ✔ | ✔ | GFM 표, 각주(`[^1]`) |
| HTML / TXT | ✔ | ✔ | TXT는 UTF-8·EUC-KR 자동 판별 |

HWP·HWPX 저장 결과는 한글 2018에서 실제로 열어 확인했습니다 (`tests/hangul/` 참고).

## 한글과 같은 주요 기능

- **쪽 단위 편집 화면**: 실제 용지 모양으로 쪽을 나눠 보여 줌 (문단 줄 단위·표 줄 단위로 다음 쪽으로 넘김), 각주는 해당 쪽 아래에 표시
- **편집 용지(F7)**: 용지 종류/방향, 위·아래·왼쪽·오른쪽·머리말·꼬리말·제본 여백 (한글과 같은 여백 의미)
- **글자 모양(Alt+L)**: 글꼴, 크기, 장평, 자간, 진하게/기울임/밑줄/취소선, 외곽선/그림자/양각/음각, 위·아래 첨자, 글자 색, 음영 색
- **문단 모양(Alt+T)**: 양쪽/왼쪽/가운데/오른쪽/배분 정렬, 왼쪽·오른쪽 여백, 들여쓰기/내어쓰기, 줄 간격(%, 고정 값), 문단 위·아래 간격, 문단 배경
- **표**: 표 선택(왼쪽 위 ⊞ 손잡이 또는 F5 세 번 → 지우기/오려 두기/복사), 표 만들기(Ctrl+N,T), 줄/칸 추가·삭제, 셀 합치기(F5→M)/나누기(F5→S), 셀 테두리·배경·세로 정렬(F5→L), 셀 너비 같게, 제목 줄, 열 너비 끌어 조절
- **입력**: 그림(끌어 놓기·붙여넣기·크기 조절, 그림 자르기 대화 상자 또는 Shift+모서리 끌기), 하이퍼링크, 각주, 문자표(Ctrl+F10), 날짜/시간, 쪽 나누기(Ctrl+Enter), 가로줄, 인용, 코드, 체크리스트
- **쪽**: 머리말/꼬리말(쪽 번호·전체 쪽수 필드), 쪽 번호 매기기(위치·모양·시작 번호), 찾아가기(Alt+G)
- **서식 도구**: 스타일(F6), 글머리표/문단 번호 모양(가.나.다., ①②③, (1) 등), 모양 복사(Alt+C), 눈금자로 여백·들여쓰기 조절
- **편집**: 찾기(Ctrl+F)/찾아 바꾸기(Ctrl+H, 정규식·온전한 낱말), 되돌리기/다시 실행, 삽입/수정 모드(Insert), 문단 부호 보이기
- **파일**: 여러 문서 탭, 최근 문서, 자동 저장과 비정상 종료 복구, 미리 보기, 인쇄, PDF로 저장, 문서 정보(글자 수·원고지 매수)
- **화면**: 확대/축소(Ctrl+휠), 폭 맞춤/쪽 맞춤, 전체 화면(F11), 투명 선 보이기, 어두운 테마(종이까지 어둡게 할 수 있음)
- **수식(Ctrl+N,M)**: LaTeX 또는 한글 수식 문법으로 쓰고 바로 그려 봄, 분수·근호·합·적분·행렬 틀과 기호판. HWP·HWPX의 수식을 수식으로 읽고, HWPX에는 한글 수식 개체로 저장

## 서식 문서 (Ctrl+Alt+N)

파일 → 서식 문서로 새로 만들기에서 미리 보기를 보며 고릅니다. 채워 넣을 자리는 옅은 노란 바탕으로 표시되고, 날짜는 오늘 날짜로 들어갑니다.

| 분류 | 서식 |
|---|---|
| 공문·행정 | 기안문(공문: 수신·제목·항목 체계·붙임·끝·발신 명의·결재·연락처) |
| 보고 | 개조식 보고서(□ ○ - 체계), 주간 업무 보고(가로), 출장 결과 보고서 |
| 회의·일정 | 회의록(논의·결정·실행 과제), 사업(행사) 추진 계획서(월별 일정표·예산) |
| 재무·구매 | 품의서(지출 결의, 결재란), 견적서(공급자 정보·품목·세액) |
| 인사·개인 | 휴가 신청서, 이력서 |
| 홍보·안내 | 보도자료, 안내문(공지) |

서식은 `src/templates/`에 코드로 들어 있어 HWPX·HWP·DOCX로 저장해도 표와 테두리가 유지됩니다 (`node tests/test-templates.mjs`).

## 검토·도우미 기능

- **명령 팔레트(Ctrl+Shift+P)**: 모든 명령을 이름(초성 검색 가능)으로 찾아 실행, 최근 사용 명령
- **맞춤법·공문서 검사(F8)**: 자주 틀리는 말, 띄어쓰기, 공문서 표기(날짜·시각·붙임), 순화어, 문장 부호를 밑줄로 보여 주고 한 번에 고침. AI 교정도 같은 창에서
- **변경 내용 추적(Ctrl+Shift+E)·메모(Ctrl+Alt+C)**: 넣은 글·지운 글을 사람별 색으로 표시하고 하나씩 또는 모두 받아들이기/되돌리기. 메모·답글·해결. DOCX와 주고받으며 그대로 유지(다른 형식은 반영한 글로 저장). 사용자 이름은 환경 설정에서
- **선택 영역 AI 고치기**: 글자를 고르면 뜨는 막대에서 다듬기·줄이기·공문서체·쉬운 말·번역·직접 지시. 결과는 'AI' 이름의 변경 제안으로 들어가 그 자리에서 받아들이거나 되돌림
- **AI 도우미**: Claude·GPT·Gemini(API 키) 또는 **Ollama 로컬 모델**(키 없이, 문서가 이 컴퓨터 밖으로 나가지 않음). 설정(⚙)에서 Ollama 주소를 바꿀 수 있음
- **AI 앱 연결(MCP)**: 문서 읽기·개요·선택 영역·내용 넣기·블록 바꾸기·찾아 바꾸기·문단 스타일·표 넣기·메모 달기/답글·변경 목록/받아들이기·저장(항상 확인). "AI 앱의 수정을 변경 제안으로 남기기"를 켜면 AI가 고친 곳이 앱 이름의 변경 내용으로 표시됨
- **개인정보 찾기·가림**: 주민등록번호·전화·이메일·카드(Luhn 검사)·계좌(추정)·여권·운전면허 번호를 찾아 부분 또는 전체 가림. 변경 추적 중에도 원래 글을 남기지 않음
- **버전 기록(Ctrl+Alt+H)**: 저장할 때와 편집 중 5분마다 이 컴퓨터에 사본을 남기고, 이름 붙이기·지금과 비교(문단·낱말 단위)·되돌리기·새 탭으로 열기
- **실시간 공동 편집(실험)**: 같은 네트워크의 Kite끼리 접속 코드로 한 문서를 함께 고침. 상대 커서와 이름이 보이고, 되돌리기는 내가 고친 것만 되돌림

단축키 전체 목록은 프로그램의 **도구 → 단축키 목록(Shift+F1)** 에 있습니다.

## Microsoft Store 배포

```
npm run dist:msix       # 맥·윈도우 어디서나 → release/Kite-<버전>-x64.msix (스토어 제출용, 서명 없음)
npm run dist:store      # 윈도우에서만: electron-builder 의 makeappx 로 → release/*.appx
```

`dist:msix` 는 `scripts/pack-msix.mjs` 가 윈도우 도구 없이 MSIX 규격(OPC 꾸러미, 64KB 블록 지도)대로 직접 묶는다. 스토어 제출 패키지는 Microsoft 가 서명하므로 서명하지 않는다. 직접 설치해 시험하려면 서명해야 한다.

제출 전에 채울 값:

- `package.json` → `build.appx` 의 식별 값은 Partner Center 값(minary.KiteWord, 게시자 minary)으로 넣어 두었다. `displayName` 은 Partner Center 에 예약한 앱 이름과 같아야 한다
- `src/appInfo.ts` → `CONTACT_FORM_ENDPOINT` 또는 `CONTACT_FORM_KEY`(문의 양식), `PRIVACY_URL`(아래 처리방침을 올린 웹 주소)
- `PRIVACY.md` 의 문의처. 이 내용을 웹에 올리고 그 주소를 Partner Center 의 개인정보 처리방침 칸에도 넣는다

스토어판에서 달라지는 점 (MSIX 로 설치되면 자동, 시험할 때는 `KITE_STORE=1`):

- 한컴오피스 전용 글꼴 읽기를 끈다 (한컴오피스용 글꼴의 라이선스 문제)
- Claude 데스크톱 등록은 설정 파일에 직접 쓰지 않고, 넣을 내용을 복사해 설정 파일을 열어 준다 (MSIX 의 AppData 쓰기 가상화)
- AI 앱이 Kite 를 실행할 때는 실행 별칭 `kite-word.exe` 를 쓴다 (`build/appx/extensions.xml`)

모든 판에 공통으로, 클라우드 AI 로 처음 보낼 때 동의를 받고, AI 응답마다 신고 단추가 있으며, 도구 메뉴에서 개인정보 처리방침과 오픈소스 라이선스(`npm run build` 때 `scripts/gen-notices.mjs` 가 만든다)를 볼 수 있다.

본 제품은 한글과컴퓨터의 한/글 문서 파일(.hwp) 공개 문서를 참고하여 개발하였습니다.

## 한글(HWP·HWPX)과 같은 모양으로 보이기

한글이 파일에 넣어 둔 첫 쪽 미리 보기 그림(PrvImage)을 기준으로 Kite 화면과 겹쳐 비교하며 맞췄다.

- 글꼴이 없을 때의 글자 폭: 문서의 글꼴이 이 컴퓨터에 없으면 한글·한자는 어느 한글 글꼴이든 글자 크기와 같은 폭(1em)이므로 그 폭으로 줄을 바꾼다 (`hwpMetrics`). macOS 의 기본 한글 글꼴(Apple SD Gothic Neo)은 0.865em 이라 그대로 두면 줄이 한글보다 일찍·늦게 바뀐다. 대체 글꼴은 나눔·애플 명조/고딕 순
- 칸 그러데이션 채우기(제목 띠 등), 떠 있는 표의 세로 위치(문단 기준 오프셋), 표 바깥 여백(위·아래)을 반영한다
- 한컴오피스 전용 글꼴(휴먼명조·HY 계열)이 없는 컴퓨터에서는 글자 모양은 다르지만 줄 바꿈·표 크기는 같다

## 알려진 제한

- HWP/HWPX의 떠 있는 개체(글 뒤로/앞으로 배치한 그림·글상자)는 본문 흐름에 차례대로 배치됩니다.
- 다단, 바탕쪽은 아직 지원하지 않습니다.
- 수식: 한글 수식 문법은 자주 쓰는 범위만 변환합니다. DOCX·HWP·ODT 등에는 한글 수식 문법 글자로 저장됩니다. HWPX에 쓴 수식의 크기는 어림값이며 한글이 열 때 다시 계산합니다.
- 변경 내용·메모는 DOCX에서만 그대로 주고받습니다. HWP·HWPX·PDF 등으로 저장하면 변경을 반영한 글만 남고 메모는 빠집니다 (저장할 때 묻습니다).
- 실시간 공동 편집은 실험 기능입니다. 본문만 함께 고쳐지고 메모 내용·쪽 설정 변경은 나누지 않으며, 파일 저장은 연 사람이 합니다.
- 쪽 나누기는 화면 배치 기준이라 한글과 쪽 수가 조금 다를 수 있습니다.
- 표의 한 줄이 한 쪽보다 길면 그 줄은 나누어지지 않습니다.
